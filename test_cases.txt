MindEase prototype test checklist

1. Start fresh: application should create/ask for student profile and load no records.
2. Student mood check-in: add mood 4 and verify it appears in mood history.
3. Invalid mood: enter 9, abc, then 3; app should reprompt and accept 3.
4. Journal without mood: should ask student to create a mood entry first.
5. Add journal: add text to latest mood and verify it appears in history.
6. Undo journal: undo should restore previous journal text.
7. Undo mood: add mood, undo, and verify it is removed.
8. Reminder FIFO: add A then B; show next should return A.
9. Resource lookup: stress and STRESS should both find tips.
10. Unknown resource: xyz should report no resources found.
11. Doctor login wrong password: access should be rejected.
12. Doctor login correct password but consent OFF: doctor records should remain blocked.
13. Student enables doctor consent; doctor can view mood history.
14. Doctor analytics: entry count and average should match entered moods.
15. Doctor journal review: only non-empty shared journal entries should display.
16. Doctor feedback: feedback should save and appear in student feedback page.
17. Student revokes consent; doctor should no longer see records.
18. Save and restart: mood entries and profile should reload.

Fill the Observed column/results after manually running each test.
